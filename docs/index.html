When an alert fires, it finds the matching runbook, proves the root cause from the service's own logs, cites the log lines and lists next steps. If the logs confirm nothing, it says UNKNOWN instead of guessing. Source code · Documentation (PDF)

How it works

1Alert firesrules over HOI's own logs: error rate, latency, 401/429 spikes, readiness
2Retrievehybrid search over 16 runbooks: BM25 + LSA, Reciprocal Rank Fusion
3Verifyrun each runbook's checks against the logs with read-only tools
4Groundthe runbook must exist and every cited log line must exist
5Reportroot cause, evidence, next steps, or UNKNOWN
